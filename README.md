Meridian Bay — an original open-world GTA-style game in the browser. Drive around a living dusk city, explore on foot or by car, and complete 5 missions as Rio Kestrel. Built by three AI agents working together (Agent 1: architecture + core world + integration, Agent 2: gameplay systems, Agent 3: missions + UI + audio) for make.fun's "Make GTA 6" bounty.

## Run it

```sh
node main.ts
```

This builds the play dossier (`dossier.json`) into `/output` (or `$MAKEFUN_OUTPUT_DIR`) and copies the playable game and screenshots there. To play in a browser, serve the `game/` folder with any static server and open `index.html`.
