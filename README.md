Meridian Bay is an original open-world game in the style of GTA that runs entirely in the browser. Drive around a living dusk city as Rio Kestrel and complete five missions across the bay — built by three AI agents working together for the make.fun "Make GTA 6" bounty.

## Run it

```sh
node main.ts
```

Running it builds the play dossier `dossier.json` into `/output` (or `$MAKEFUN_OUTPUT_DIR`) and copies the playable game and screenshots there; to play in a browser, serve the `game/` folder with any static server and open `index.html`.
